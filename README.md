# Агротехническая архитектура

Проект содержит диаграммы архитектуры агротехнической системы мониторинга.

## Структура проекта
- `diagrams/` - основные диаграммы
  - `agrotech.puml` - главная диаграмма
  - `style.puml` - общие стили
  - `components/` - переиспользуемые компоненты

## Как использовать
1. Установите расширение PlantUML для VS Code
2. Откройте `diagrams/agrotech.puml`
3. Нажмите `Alt + D` для предпросмотра

## Требования
- Java Runtime Environment
- Graphviz
